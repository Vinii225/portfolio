# Portfolio

Página estática que reúne meus projetos atuais e futuros, pra facilitar a visualização por outras pessoas.

- `index.html`: conteúdo
- `css/style.css`: estilos (mesma paleta do README do meu perfil)
- `js/main.js`: animações de entrada e reveal ao rolar, sem dependências
- `assets/`: favicon e imagens

A pipeline em `.github/workflows/pipeline.yml` valida o HTML com htmlhint e publica no GitHub Pages a cada push na `main`.
